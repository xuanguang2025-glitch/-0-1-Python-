# 五级提示阶梯（hint_ladder.md）

> 与 `backend/app/services/ai/prompts.py::LEVEL_PROMPTS` 保持同步。
> `level` 由请求参数控制，**逐级解锁**，默认 `hint`。

| level | 中文 | 输出要求 |
|---|---|---|
| `hint` | 提示 | 只给一句方向性提示，不涉及具体代码，让学员自己迈出第一步 |
| `approach` | 思路 | 给出解题/排查的整体思路与步骤大纲（有序列表），不写完整代码 |
| `partial` | 局部提示 | 给出关键的一两个局部片段或函数骨架，其余留给学员完成 |
| `full` | 完整解释 | 给出完整实现，并逐段解释为什么这样做 |
| `explain` | 深度讲解 | 在完整解释基础上，补充原理、复杂度、易错点与延伸阅读方向 |

## 练习模式约束（强制）

当前处于练习模式时：

- **禁止直接给出完整可运行答案**；
- 只给方向、关键概念、定位方法或小的局部片段（不含完整解题函数/完整程序）；
- 不输出可直接复制提交的最终代码；
- 如需示例，用「伪代码」或「填空式片段」（含 `TODO` / `...` 占位）；
- 用户显式请求 `full` / `explain` 时，后端返回 `403 AI_FULL_ANSWER_DISABLED`，
  除非 `AI_ALLOW_FULL_ANSWER_IN_DRILL=true`。

## 输出后置检查（后端）

除提示词约束外，服务端还会对输出做**后置裁剪**：删除被「完整答案 / 完整代码 /
参考实现 / 解答」类标题引导的代码块，避免变相泄露完整答案。
